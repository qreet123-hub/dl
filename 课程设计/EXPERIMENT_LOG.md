## 1. 项目目标

本项目实现一个面向心脏医学图像的两阶段级联分割框架，核心目标是验证：

> 在 MyoPS 2020 多模态心肌病灶分割任务中，引入由 ACDC 数据集训练得到的解剖定位先验 mask，是否能够提升正常心肌、水肿和疤痕等目标区域的分割效果。

整体任务分为两个阶段：

1. **第一阶段：U-Net-Locator**
   - 训练数据：ACDC 数据集。
   - 输入：单通道 bSSFP 图像。
   - 输出：左心室 + 心肌区域的二值粗定位 mask。
   - 目标：学习心脏解剖结构的空间先验。

2. **第二阶段：U-Net-Segmentor**
   - 训练数据：MyoPS 2020 数据集。
   - 输入：LGE、T2、bSSFP 三模态图像，以及第一阶段定位器输出的 mask。
   - 输出：四分类分割结果，即背景、正常心肌、水肿、疤痕。
   - 目标：利用三模态信息和解剖先验进行精细分割。

同时实现一个对比基线：

- **Baseline U-Net**：仅使用 MyoPS 的 LGE、T2、bSSFP 三通道输入，不使用定位 mask。
- **Cascade U-Net**：使用 LGE、T2、bSSFP 和定位 mask 四通道输入。

## 8. 针对当前的改进

### 8.1 损失函数改进

当前第二阶段只使用加权 DiceLoss，修改为：

```text
Loss = WeightedDiceLoss + 0.5 × WeightedCrossEntropyLoss
```

- DiceLoss 关注区域重叠，但小目标训练不稳定；
- CrossEntropyLoss 对像素级分类更直接；
- 二者结合通常能提升水肿、疤痕等小目标类别的学习效果。

同时修改类别权重：

```python
weights = [0.1, 1.0, 4.0, 4.0]
```

对应：

| 类别 | 建议权重 |
|---|---:|
| 背景 | 0.1 |
| 正常心肌 | 1.0 |
| 水肿 | 4.0 |
| 疤痕 | 4.0 |

### 8.2 训练轮数改进

当前第二阶段训练轮数：

```python
EPOCHS_SEGMENTOR = 40
```

改为：

```python
EPOCHS_SEGMENTOR = 80
```

原因：

- 当前使用随机初始化编码器，没有 ImageNet 预训练；
- 需要更多训练轮数收敛；
- 小目标类别学习更慢。

### 8.3 采样策略改进

增加病灶切片采样策略：

- 对包含水肿或疤痕的切片提高采样概率；
- 或者过滤掉一部分纯背景/极少前景切片；
- 保证每个 batch 中更频繁出现病灶区域。

预期：

- 提高水肿类别 Dice；
- 缓解类别不平衡；
- 减少模型只学习正常心肌和背景的倾向。

### 8.4 定位 mask 质量检查

检查当前分割图片：

```text
D:\a\results\figures
```

1. 定位 mask 是否覆盖心肌区域；
2. 定位 mask 是否过大，包含大量背景；
3. Cascade 是否因为定位 mask 过宽而预测过多前景；
4. 黄色水肿区域是否几乎没有被预测。

如果定位 mask 质量差，应优先优化第一阶段定位器。

### 8.5 更严格的数据划分

当前数据划分是切片级随机划分。后面可以改成病例级划分：

- 训练集病例；
- 验证集病例；
- 测试集病例；
- 同一病例的所有切片只出现在一个集合中。

## 9. 阶段性结论

当前项目已经完成两阶段级联心脏医学图像分割框架的搭建与运行。实验实现了 ACDC 定位器、MyoPS 三通道 Baseline U-Net 和加入定位 mask 的四通道 Cascade U-Net。当前阶段性结果显示，引入定位 mask 后，正常心肌 Dice 从 `0.8702` 提升到 `0.8887`，疤痕 Dice 从 `0.4928` 提升到 `0.5299`，疤痕 HD95 从 `11.3469` 降低到 `10.5280`，说明解剖先验对部分结构和病灶分割具有一定帮助。

但当前水肿类别 Dice 几乎为 0，且 Cascade 背景 Dice 明显下降，说明模型仍存在类别不平衡、小目标学习不足、定位先验可能过宽等问题。后续需要通过重新训练、混合损失函数、提高水肿和疤痕权重、增加训练轮数、优化采样策略和采用病例级划分等方式进一步改进。
